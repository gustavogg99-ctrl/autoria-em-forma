# Método e regras de revisão

Estes são os documentos que orientam a IA e o revisor humano no serviço da Autoria em Forma. O código do repositório executa o que eles decidem: a IA decide **o que** corrigir, o código garante **como**.

| Arquivo | O que é |
|---|---|
| [`00_instrucoes_do_projeto.md`](00_instrucoes_do_projeto.md) | Instruções do operador (o prompt do projeto): regras inegociáveis, hierarquia de regras e fluxos (ORÇAMENTO, TRIAGEM, REVISÃO, REFERÊNCIAS, QA FINAL) |
| [`01_checklist_qa_abnt.md`](01_checklist_qa_abnt.md) | Checklist de QA rodado antes de toda entrega |
| [`04_guia_modelo_word_abnt.md`](04_guia_modelo_word_abnt.md) | Como montar e aplicar um modelo ABNT no Word, à mão |
| [`05_matriz_manuais_df.md`](05_matriz_manuais_df.md) | Regras, contradições e decisões por instituição do DF (UCB, IESB, CEUB, IDP, UDF, UNIP, UNICEPLAC, UnB) |
| [`06_licoes_aprendidas_tcc.md`](06_licoes_aprendidas_tcc.md) | Erros cometidos em trabalhos reais, regras operacionais, versão marcada e fluxo do pipeline |
| [`08_template_relatorio_entrega.md`](08_template_relatorio_entrega.md) | Mapa Normativo e relatório de entrega |
| [`09_decisoes_por_curso_exemplo.md`](09_decisoes_por_curso_exemplo.md) | Exemplo de arquivo de decisões de um curso (anonimizado) |
| [`10_resultado_teste_cronometrado.md`](10_resultado_teste_cronometrado.md) | Teste à mão × pipeline com documento fictício (n=1) |

**Nomes antigos nos textos:** os documentos citam os arquivos pelos nomes que tinham no projeto (`01_Checklist_QA_ABNT.md`, `claude/Decisoes_*`, `claude/08_...`). Eles correspondem aos arquivos acima. Os arquivos 02, 03 e 07 (preços, mensagens e estratégia comercial) não foram publicados.

**Anonimização:** trechos, nomes e temas de trabalhos de clientes foram trocados por marcadores entre colchetes, como [TRECHO DO TRABALHO], [INSTITUIÇÃO] e [CURSO].

**Normas e manuais:** os textos das normas ABNT e dos manuais das instituições não estão aqui. Os documentos citam o número da norma, o item e a página, e transcrevem no máximo uma frase de cada item.
